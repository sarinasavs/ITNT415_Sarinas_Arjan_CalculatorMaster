## Overview
A modular, menu-driven Python calculator built using a Git/GitHub feature-branch workflow. Each arithmetic operation was implemented on a dedicated branch and merged into `main` via Pull Requests.

## Features
- **Interactive Menu:** Choice-based interface for Addition, Subtraction, Multiplication, Division, and Exit.
- **Input Validation:** Handles non-numeric inputs gracefully by re-prompting the user.
- **Error Handling:** Safe division logic that catches division-by-zero errors.
- **Modular Design:** Functions for each operation kept cleanly separated.

## Branch Structure
- `main` — Integrated production code
- `addition_Arjan` — Addition feature branch
- `subtraction_Arjan` — Subtraction feature branch
- `multiplication_Arjan` — Multiplication feature branch
- `division_Arjan` — Division feature branch
